# 💳 برنامه مدیریت و اسکن کارت‌های بانکی (PWA)

اپلیکیشن وب سبک و بدون نیاز به سرور جهت ذخیره، اسکن و مدیریت کارت‌های بانکی.

## ✨ ویژگی‌های کلیدی
- 📷 **اسکن هوشمند کارت:** خواندن خودکار شماره کارت و شماره شبا با دوربین (OCR) بدون نیاز به تایپ دستی.
- 🎨 **تشخیص هوشمند بانک:** شناسایی خودکار نام و فریم رنگی بانک بر اساس پیش‌شماره (BIN).
- 📱 **بهینه‌سازی iOS:** قابلیت نصب مستقیم روی صفحه اصلی آیفون (Add to Home Screen).
- 🔒 **۱۰۰٪ امن و محرمانه:** پردازش تصویر و ذخیره‌سازی داده‌ها تماماً روی مرورگر گوشی (Local Storage) انجام می‌شود و هیچ اطلاعاتی به سرور ارسال نمی‌شود.
- 📋 **کپی سریع:** امکان کپی شماره کارت، حساب و شبا با یک لمس.
- ↕️ **مرتب‌سازی:** امکان جابه‌جایی و تعیین اولویت کارت‌ها.
